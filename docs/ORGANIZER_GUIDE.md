# 队长指南

## 在公开活动中建队

打开活动的“同行”，填写管理员提供的本活动建队码和小队标题，创建小队。建队码默认24小时有效，只能建立一支小队；队员加入只需邀请链接。

在小队“成员”→“管理小队”复制邀请，单独保存队长恢复入口。邀请可发群，管理入口只自己保管。队长参与活动时也以自己的队员身份填写，不能替别人提交或读取私人备注。

已有个人计划时，主动“同步本人计划到此小队”，核对后“提交”。参加多个小队要分别同步、提交，个人计划不会自动公开，收藏和路线也不共享。

## 发起日常活动

首页点“发起日常活动”，填写名称、日期、候选时间和站点创建码。创建后可先安排个人计划，再到“同行”建队。私人活动不进入公开列表；朋友通过邀请进入对应活动和小队。

创建者在“我的”→“编辑活动资料”修改，先“预览修改”，再“确认保存活动资料”。未确认修改保存在本机。个人恢复链接与活动管理链接是不同权限，分别保管。

## 查看进度和共同空闲

“成员”显示已加入与已确认的人数；未打开邀请的人不计入。队员各自提交后，在“共同空闲”看准确时间。有人未确认或需复核时，等待提示会保留。比较部分人要明确选择，不能把子集结果当全队结果。

## 更新活动资料

公共活动小队保存独立快照。管理员更新后，队长在“活动资料”点“核对并更新活动资料”，确认差异；不会自动覆盖本队。

私人小队使用“导入活动文件”，支持文件和文本。先“预览”，核对新增、修改、删除和时间影响，再“确认导入”。错误包整包拒绝，活动导入不包含任何个人回复。格式见 [JSON 说明](EVENT_JSON_FORMAT.md)。

时间、开放范围或场次变化后，旧回复保留并要求队员重新确认；纯标题修改不要求重填。已有确认回复后不能直接改时区，应另建活动。版本冲突时重新预览。

## 管理邀请和成员

“更换邀请链接”使旧邀请不能再加入，既有队员权限保留。移除成员会撤销其在线访问权限，无法远程删除其已下载副本。同名队员是不同身份，操作前核对。

“关闭填写”停止加入和回复，“归档”用于收尾。“删除小队”需再次确认并删除云端小队与凭据；清除本机记录不会删除云端。删除前导出所需资料。

地点可通过“分享地点”发出公开链接，不带私人权限。完整集合提议的接受、拒绝流程尚未提供。
