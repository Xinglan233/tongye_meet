# 开发交接

## 接手顺序

1. 阅读 [README](../README.md) 和 [文档中心](README.md)。
2. 核对 [功能状态](ACTIVITY_P0_STATUS.md)、[发布证据](RELEASE_CHECKLIST.md) 和实际部署版本。
3. 阅读 [架构](ARCHITECTURE.md)、[API](API.md)、[JSON](EVENT_JSON_FORMAT.md)、[日期时间](DATETIME.md) 与 [安全说明](../SECURITY.md)。
4. 按 [测试](TESTING.md) 启动本地隔离环境；部署与恢复按对应维护文档执行。

完整需求原文与来源索引保存在 `handoff/`，可转交包同时保留原执行包、活动升级MD、视觉要求、用户参考图与后续决策。当前公开文档优先描述已发布行为；历史暂停和阶段状态由最新发布记录覆盖。

## 必须保留

用户确认的Figma界面及公共组件；活动四入口；现有URL与旧数据兼容协议；1分钟精度；独立收藏、安排、路线；个人保存与逐队提交；高熵权限作用域、CAS、幂等、预算、离线草稿保护；免费与环境隔离。

不得通过昵称认领身份、把草稿当已提交、把场次选择当预约、为视觉完整编造地图路线，或为测试降低保护。代码和文档提交走正常PR与CI，不绕过分支规则。

## 私密资料

交接包不含密码、token、管理员会话、临时访问链接、私人SQL或原始工具日志。维护者需要配置时，由账号持有人通过安全渠道提供；不从浏览器、登录文件或会话存储抽取。

生产完整媒体备份仍需合法受控管理员会话。既有SQL备份和公开显示图核验不能代替它。回滚按 [运维](OPERATIONS.md) 确认实际上一生产部署，不固定已经过时的部署ID。

## 2026-10-05 现场使用修复（仅待验预览）

公开发布活动可直接建队，服务端使用当前发布快照；私密及自定义建队仍走原创建码。创建者与邀请、管理凭据分开保存，入队失败沿用同一操作与成员令牌重试。小队资源设置64MiB、1000队全局及每活动100队的原子预算，覆盖快照、成员与回执；24小时/每作用域64条回执及7天/10000条删除记录有界，组相关审计最多10000条；限流最多10000作用域，保留当前窗口计数，有界回收过期行。审计与限流各预留10MiB元数据空间，独立于个人及媒体预算。

地图使用与当前完整活动包、权限范围、地图清单和图片哈希精确匹配的ready缓存先显，后台刷新不混用旧坐标。首页公开列表缓存先显；没有准备的冷启动不能宣称离线可用。基础SW预缓存移除OCR引擎及语言包；明确准备时校验完整识别资源，准备状态与构建清单绑定，真实生产SW断网重启识别已在本地验证。

日期使用活动时区的今天（超出活动日期则起始日），所选日期及筛选保留，探索与详情仅列当天场次。操作统一为加入计划、已加入计划、移出计划；收藏和路线独立。更新本队空闲明确目标小队与活动范围，只提交本队，剔除私人备注，个人备份单独操作。

呈现复用指定Make HVEkdtjmMHYBIUQ5LT5ynW及已保存V14/V18导出的标题输入、按钮、日程和管理面板；六项原始Make文件哈希与provenance一致。当前MCP仅读到源码资源清单，未获得最新画面；本轮未在Figma生成新布局，不将复用视为新增布局设计验收。所有浏览器证据为本地隔离夹具，不能代称REDLAND真机现场网。

只允许draft PR、受保护Preview和隔离staging；不合并main，不迁移生产D1，不部署production Worker，不更改生产env/域名。预览上线与真实CI结果单独核验，尚不能把本地通过写成云端验收。

审查修复使用增量0010：超额时删除仍保留幂等回执并净释放预算，过期清理独立有界提交，避免失败业务写回滚清理进度。OCR准备请求版本化，支持A→B升级后重新准备。小队提交在本机写入前捕获草稿generation及身份，成功不清除后续编辑；个人冲突核对的迟回仅作用相同活动、身份、草稿generation与版本。真实邀请生成器携带所选date，权限仍只由原fragment凭据决定。

OCR清单与运行页面编译进同一构建标识，不按全局CacheStorage搜索结果判定版本。A控制页面、B等待激活时，准备B会提示先保存后更新，保留A的ready标记和资源，不刷新页面或清草稿。真实SW回归覆盖该拒绝后的A断网重启、现有更新按钮切换B、B准备后断网识别和损坏资源拒绝；失败、配额不足仍保留上次完整准备。
